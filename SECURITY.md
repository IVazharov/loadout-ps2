# Security

Loadout downloads and installs its own updates, and Loadout Bay listens on the network for Loadout and writes to the PS2's hard disk. If you find a way to misuse any of that, please report it privately: on this repository's **Security** tab, press **Report a vulnerability**, or go to [github.com/IVazharov/loadout-ps2/security/advisories/new](https://github.com/IVazharov/loadout-ps2/security/advisories/new). Please don't open a public issue for it.

Loadout Bay has no password: while it runs, any computer on the same network can talk to it, as with other PS2 network tools. Run it on a network you trust, such as your home network, and close it when you're done.

Only the latest release gets fixes. There is no fixed response time, but every report is read.
